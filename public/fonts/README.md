# Fonts

## texgyrebonum-bold.woff2

TeX Gyre Bonum Bold, version 2.004, a free font in the style of Bookman Old Style. It's used for the
sign-in dialog's headings (`.font-bookman` in `src/app/(storefront)/globals.css`) on devices that don't
have Bookman Old Style installed.

- Source: GUST e-foundry, https://www.gust.org.pl/projects/e-foundry/tex-gyre/bonum (`qbk2.004otf.zip`,
  `texgyrebonum-bold.otf`).
- Copyright 2006, 2009 for TeX Gyre extensions by B. Jackowski and J.M. Nowacki (on behalf of TeX users
  groups).
- Licence: GUST Font License, https://tug.org/fonts/licenses/GUST-FONT-LICENSE.txt
- This copy is the original font converted to WOFF2 and reduced to the Latin, punctuation and ₹ characters the
  site uses (with fontTools `pyftsubset`). The glyphs themselves are unchanged.
